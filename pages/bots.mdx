Chief Tools bots fetch public internet resources for monitoring and lookups. This page explains how to recognize those requests and where to report a problem.

## Recognize a Chief Tools bot

Where the protocol supports it, a Chief Tools bot identifies itself with a user agent containing one of these patterns:

```text
AppName/X1X2X3X4
AppNameBot/X1X2X3X4
```

For example, Cert Chief may send this user agent while monitoring a domain:

```text
CertChiefBot/X1X2X3X4 (+https://aka.chief.app/bot)
```

The <ExternalLink href="https://favicon.chief.tools">Chief Tools favicon service</ExternalLink> may identify itself inside a browser-style user agent:

```text
Mozilla/5.0 AppleWebKit/537.36 (KHTML, like Gecko; compatible; ChiefToolsFaviconBot/X1X2X3X4; +https://aka.chief.app/bot) Chrome/123.0.6312.58 Safari/537.36
```

<Callout type="info" title="Match the bot name, not its version">
  `X1X2X3X4` stands for a version identifier such as `040bd810` or `1.0.0`. The format and value can change, so do not require an exact version when matching a Chief Tools user agent.
</Callout>

A user agent is self-reported and can be copied by another client. Use a product's bot page for any additional verification information it publishes.

## Product-specific bot details

- [Cert Chief bot information](/certchief/bot) lists its purpose, behavior, user agents, and IP addresses.

## Report unexpected traffic

If a Chief Tools bot is causing a problem, use our <ExternalLink href="https://chief.app/contact">contact form</ExternalLink>. Include the requested URL, the complete user agent, the approximate request time with its time zone, and a short sample of the relevant access-log entries. Remove cookies, credentials, and unrelated personal data before sending logs.
