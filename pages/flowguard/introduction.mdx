FlowGuard is an <ExternalLink href="https://github.com/chieftools/flowguard-proxy">open-source reverse proxy</ExternalLink> for filtering and controlling HTTP and HTTPS traffic. You can match requests by IP address, path, headers, country, ASN, user agent, and other request data, then allow, block, log, or rate limit them.

The <ExternalLink href="https://flowguard.network">FlowGuard control plane</ExternalLink> manages multiple self-hosted proxy instances from one dashboard. It provides request logs, traffic analytics, rules, IP lists, health checks, and managed IP reputation feeds while the proxies keep application traffic on your servers.
