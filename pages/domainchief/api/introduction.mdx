The Domain Chief API lets you manage domains, contacts, DNS records, and redirects from your own software. You can also check domain availability, read TLD pricing, and retrieve domain activity.

Authenticate each request with an [access token](/api/tokens#access-tokens). Give the token only the [scopes](/domainchief/api/scopes) your integration needs.

Use the [API playground](/api/domainchief) to inspect endpoints and send test requests. Sign in with your Domain Chief account when the playground asks for authentication.
