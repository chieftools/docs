Domain Chief is a registrar and domain management service. Use it to register or transfer domains, manage contacts and nameservers, edit hosted DNS records, and configure web or mail redirects. Domain registrations use WHOIS privacy by default where the registry supports it.

Choose the interface that fits the job:

- Use the Domain Chief web app for day-to-day domain management.
- Use the [REST API](/domainchief/api/introduction) for application integrations and scripts.
- Connect an [AI agent through MCP](/domainchief/ai) when you want the agent to inspect or change supported resources.

Developers who provide hosting, email, or another service can also integrate through [Domain Connect](/domainchief/developers/domain-connect). Domain Chief shows the proposed DNS records and asks the domain owner to approve them.
