Backup Chief does not have a public API yet. Manage servers, storage, and backup jobs from the Backup Chief dashboard for now.

Looking for help using Backup Chief in the browser? Go to the [Backup Chief documentation](/backupchief/introduction).

## Request API access

If your integration needs a Backup Chief API, tell us what it should do. Suggest it on the <ExternalLink href="https://roadmap.chief.tools?ref=chiefdocs">roadmap</ExternalLink> or <ExternalLink href="https://chief.app/contact">contact us</ExternalLink>. Real use cases decide what the API covers first.
